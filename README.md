# 📚 Library Management System

A professional Library Management System built with **Python, SQLite and Streamlit**.

This application provides an easy-to-use interface for managing books, tracking book availability, issuing and returning books, searching library records, and analyzing library data.

🔗 Streamlit Live App: Coming Soon (https://library-management-system-mobsljmbefzuhgkqw6nhvk.streamlit.app)

- 📕 Issued Books Tracking

▶️ How to Run Locally

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Open the project folder:

cd Library-Management-System

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

The application will open in your browser.
